# api-testing-ecommerce
Manual API testing project for an e-commerce platform (FakeStore API) | Postman · JIRA · REST API · JSON | 28 test cases · 6 bugs logged

- Designed and executed 28 test cases across Auth, Products, Users 
  and Carts modules covering GET, POST, PUT, PATCH, DELETE operations

- Identified 6 defects including a critical security bug where DELETE 
  endpoint worked without any authorization token

- Built reusable Postman collection with environment variables and 
  pre-request auth script — reduced manual effort across test cycles

- Logged all bugs in JIRA with severity, priority, and reproduction 
  steps with Postman request/response screenshots attached
